# ml-login-secury — releases

Repositório público somente com os pacotes oficiais (ZIP) do plugin **ml-login-secury**, da ML Lopes Design.

O plugin instalado no WordPress consulta este repositório para oferecer atualizações automáticas. O código-fonte fica em um repositório privado.

Cada versão publica um único arquivo: `ml-login-secury-vX.Y.Z.zip`.
